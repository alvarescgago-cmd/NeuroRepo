# Neurología · Preguntas tipo test

Banco interactivo de 340 preguntas tipo test de Neurología (24 temas: T01–T23 + anexo T17), con respuesta y explicación.

- **Modo aleatorio:** 25 preguntas al azar de todo el temario.
- **Modo por tema:** todas las preguntas de un tema o de un bloque completo (opción de barajar el orden).
- Corrección **instantánea** por pregunta («Ver corrección») o **de todas al final** («Corregir todas»).
- Resultados con aciertos, fallos, en blanco, nota neta (−1/3 por fallo), desglose por tema y repaso de fallos.
- Guarda el progreso y las estadísticas en el navegador. Funciona sin conexión.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo y sube `index.html` (y este README).
2. *Settings → Pages → Build and deployment*: Source **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. En 1–2 minutos estará en `https://<tu-usuario>.github.io/<nombre-repo>/`.
